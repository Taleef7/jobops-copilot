Base URL of your running JobOps Copilot API service.

Created in your web app: JobOps Settings → Chrome Extension Access Tokens

How it works

  • Zero Credentials Stored: Your password and Clerk session never enter the extension. Only a scoped PAT is used.
  • Strictly Scoped: Tokens are restricted solely to /api/ext/* endpoints and can be revoked at any time.
  • Human Review Invariant: The extension assists by filling form fields and detecting submission confirmations. It never clicks Submit automatically.
